# NeXXXUs Linux node 0.7.0

Два хоста, обмен контактами, шифрованный канал, чат и файлы.

Рукопожатие **v3**: X25519 4DH + Ed25519-подпись HELLO. Отпечаток `nxx1…` считается из публичного X25519 ключа. Фраза BIP39 на диске лежит в `identity.bin`, закрытом `machine.key`.

Сейф — журнал `map.bin`, закрытый ключом сейфа. Чанки по 16 КБ адресуются хешем шифртекста. Чужая копия не совпадает с локальной побайтово, и нода-хранитель не получает ключ. Владелец время от времени спрашивает случайный чанк: ответ — отпечаток шифртекста вместе с одноразовым вопросом. Неверный ответ снимает эту копию. Журнал дополнительно лежит у контакта под меткой, выведенной из ключа сейфа. Молчащую копию владелец снимает только через льготный срок, по умолчанию 24 часа. Неверный ответ снимает копию сразу. В обоих случаях эта нода 30 суток не получает новых чанков от этого владельца: уже лежащие чужие шифртексты из-за рейтинга не стираются, а замена уходит на другую ноду. Рейтинг местный, общего голосования сети нет.

Каталог `drive` в папке ноды — открытая копия сейфа, не зашифрованный архив.

Профиль `onion` (`--profile onion --tor-socks 127.0.0.1:9050 --advertise <v3>.onion`) слушает только localhost и звонит лишь на v3-адреса через SOCKS. Прямой IP отвергается. Лабораторный профиль `lab` остаётся по умолчанию и луковые контакты не принимает. Нода не запускает Tor и не генерирует onion-адрес.

## Установка

Нужен **Node.js 22+**.

```bash
git clone https://github.com/PerfectFriend/NeXXXUs-Grok.git
cd NeXXXUs-Grok/linux-node
chmod +x install/install.sh
./install/install.sh
export PATH="$HOME/.local/bin:$PATH"
nexxus start
```

Или без инсталлятора:

```bash
cd linux-node
npm install
node nexxus.mjs start
```

Напечатает фразу BIP39 (один раз) и контакт:

```
nexxus:1:nxx1…:ключ@192.168.1.10:4377
```

Панель: `http://127.0.0.1:4378/`

Белый адрес в контакте:

```bash
nexxus start --advertise 203.0.113.5 --port 4377
```

Автозапуск (после `install.sh`):

```bash
systemctl --user enable --now nexxus
loginctl enable-linger "$USER"   # чтобы жило без сессии
```

## Связать два хоста

1. Поднимите ноду на A и на B.
2. Контакт A вставьте на B → «Связь».
3. Зелёная точка — чат или файл из сейфа.

Одной стороны достаточно. Недоступный адрес в контакте — самая частая ошибка.

Обе ноды должны быть **0.1.2**. С 0.1.0 / 0.1.1 не стыкуется.

## Тот же ключ на второй машине

```bash
nexxus start --data ~/.nexxus-2 --mnemonic "twelve words …"
```

## Что уже настоящее

- BIP39 → HKDF → X25519 (RFC 7748) и Ed25519
- 4DH-сессия, новая эфемерная пара на каждый сокет
- Подпись HELLO, отпечаток привязан к публичному ключу
- Смешанный контакт (чужой fp + свой pub) отвергается
- XChaCha20-Poly1305 на сессии и на сейфе
- Файлы по 16 КБ

## Что ещё не настоящее

- Tor / v2ray
- Глобальные 4 реплики
- Биржа NXX
- Android-нода

## Снятие

```bash
./install/uninstall.sh
```
